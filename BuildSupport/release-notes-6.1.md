# Aidente 6.1 · Build 21

本版修复插电暂停充电时仍使用电池、拖动上限后重复改写固件保持区间的问题，并恢复更紧凑、文字颜色固定的横向状态栏电池。

## 更新内容

- 保留硬件电量的小数，只在首次写入暂停边界时向上取整。例如 54.66% 使用 55% 边界，避免旧整数边界 54% 触发电池供电。超过新设定上限时保持当前电量，正常从低电量充电仍按设定上限停止。
- 暂停期间冻结完整上下限，拖动上限和轮询不再反复改写；恢复充电或断开电源后重置。清醒、睡眠保持分别保存，临时睡眠策略不覆盖清醒保持。
- 插电暂停仍请求适配器连接，并关闭强制放电。暂停确认使用三次新鲜实际功率读数，随后每八秒复查；持续充电或放电时明确报告控制未生效。
- 增加固件区间诊断日志，包括原始电量、上下限、激活状态和睡眠状态，便于定位服务正常但供电不符的情况。
- 电池图标恢复横向、从左向右填充。数字和充电标记统一深色，有电部分使用较浅状态色，无电部分为浅灰蓝，取消文字反色。纯图标占 20 点，内置数字占 26 点，包含左右各 1 点留白；保留 100% 和三位数功率的完整显示。
- 版本统一为 6.1 / Build 21，更新器支持从 6.0.2 升级至两段式版本号 6.1。

## 安装与升级

适用于 Apple Silicon MacBook、macOS 14 及以上。下载 DMG 后将 Aidente.app 拖入“应用程序”，或使用 ZIP。6.0.1 及以上也可通过应用内检查更新安装。

升级后如需管理充电，在应用中点击“修复控制服务”，通过 macOS 管理员授权更新应用及后台的身份登记。管理员密码只由系统弹窗接收。发行包沿用 ad-hoc 完整性签名，未经 Apple 公证；首次打开可按 macOS 提示从 Finder 右键选择“打开”。

## 验证范围

138 项充电回归检查、9 项管理员安装器检查及版本比较测试通过。使用 GitHub 已发行 6.0.2 安装包，在隔离目录验证升级到 6.1、保留旧版备份、拒绝资源篡改与版本不符的安装包。DMG 完整性、ZIP CRC、打包前后应用文件一致性、签名、arm64 架构和校验和检查通过。生产 SwiftUI 图标检查了明暗背景、0/5/50/79/100%、各充电状态、低电量模式、关闭状态颜色和功率组合。

受影响机器在修复后的短时观察中，电池功率为 0 W、适配器持续供电，修改上限后保持区间不变。计划 35 秒的睡眠测试约半秒即唤醒，只验证了切换与恢复后的供电；持续合盖睡眠、完整低电量充至上限及其他机型固件尚未完成实机验收。
