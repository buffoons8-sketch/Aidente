# Aidente 6.0.2 · Build 20

## 更新内容

- 菜单栏电池改为窄竖向样式，电量从下向上填充。仅图标占宽由 33 缩至 19 点，内置电量数字时由 37 缩至 25 点；优化浅色、深色和 100% 显示。
- 后台控制服务改为用户明确授权的管理员安装方案，保留主程序与后台身份校验、安装失败恢复及卸载前恢复电池控制。
- 充电和适配器控制串行执行并读回验证；改进睡眠/唤醒策略、异常反馈和诊断信息。
- 固件限充使用真实上限，手动暂停固定首次电量，避免轮询不断下调上限；自动放电默认关闭，保留用户已有选择。

## 安装与升级

适用于 Apple Silicon MacBook，macOS 14 及以上。将 Aidente.app 放入 /Applications；升级后进入充电管理，点击“修复控制服务”，在 macOS 系统弹窗重新授予管理员权限。

此版本沿用 ad-hoc 完整性签名，未经 Apple Developer ID 签名或公证。首次打开可能受到 macOS 提示；不需要关闭 SIP 或全局 Gatekeeper。管理员密码仅由系统弹窗接收。

新固件在电量超过限充上限时仍可能使用电池供电，不能保证暂停时始终由适配器供电。睡眠/唤醒、升级重新授权和卸载恢复仍需针对具体机器实测；逻辑测试通过不代表所有硬件验收完成。

下载提供 DMG、自动更新使用的 ZIP 和 SHA-256 校验文件。
